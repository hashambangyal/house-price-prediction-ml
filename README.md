# 🏠 House Price Prediction Project

This is a machine learning project that predicts house prices using CatBoost Regressor.

## 🚀 Features
- Predict house price based on area, bedrooms, bathrooms, city, and location
- Flask backend API
- Frontend UI for user input
- CatBoost model with high accuracy

## 📊 Model Performance
- Train R²: 0.83
- Test R²: 0.85

## ⚙️ Tech Stack
- Python
- CatBoost
- Flask
- HTML/CSS/JS
